# مشروع شبكة أبو غازي — نسخة تأسيسية

هذا مشروع Android أولي قابل للفتح في Android Studio وبنائه عبر Gradle/GitHub Actions.

## ما الموجود الآن؟
- واجهة عربية أولية RTL.
- إعدادات IP والمنفذ واسم المستخدم وكلمة المرور.
- اختبار وصول TCP إلى منفذ API.
- أقسام واجهة مبدئية للكروت والمشتركين والسرعات والمراقبة والطباعة.

## ما الذي لم يكتمل بعد؟
هذه النسخة **ليست تطبيق إدارة شبكة مكتملًا**. اختبار المنفذ لا ينفذ تسجيل دخول MikroTik API ولا ينشئ كروتًا. وظائف إدارة المشتركين والطباعة والتقارير ما زالت واجهات أولية ويجب برمجتها واختبارها على الراوتر قبل استخدامها.

## البناء محليًا
1. فك ضغط الملف.
2. افتح المجلد في Android Studio.
3. استخدم JDK 17.
4. انتظر مزامنة Gradle.
5. نفّذ `gradle assembleDebug`.
6. الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## بناء APK على GitHub
أنشئ مستودعًا فارغًا وارفع محتويات المشروع مع الحفاظ على بنية المجلدات. أضف ملف workflow الموجود في `.github/workflows/android.yml` ثم افتح Actions وشغّل Build Android APK.

## إعداد الراوتر
العنوان `192.168.1.150` والمنفذ `8728` قيم افتراضية مسبقة في الواجهة ويمكن تغييرها. لا تفتح API على الإنترنت العام. اختبر أولًا داخل LAN، وقيّد خدمة API إلى عنوان الهاتف/الشبكة الموثوقة. لا تحفظ كلمة مرور الراوتر في مستودع GitHub أو داخل الكود.
